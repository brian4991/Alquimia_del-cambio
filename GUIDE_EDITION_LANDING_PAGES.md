# Guide d'édition des Landing Pages

## Vue d'ensemble

Les trois landing pages du site sont maintenant éditables avec un éditeur de texte riche :
- **ProgramLanding** (`/`) - Page du programme de transformation
- **RetiroAmateLanding** (`/retiro-amate`) - Page du retiro
- **PsychologyLanding** (`/psychology`) - Page des services de psychologie

## Comment éditer le contenu

### 1. Identifier les sections éditables

Sur chaque landing page, les sections de texte importantes sont éditables. Pour les identifier :
- **Passez la souris** sur une section de texte
- Un **bouton bleu avec une icône crayon** apparaîtra en haut à droite
- Ce bouton indique que la section est éditable

### 2. Modifier une section

1. **Cliquez sur le bouton bleu** (icône crayon)
2. Un **éditeur de texte riche** s'ouvre avec le contenu actuel
3. Le contenu existant est déjà pré-rempli - vous pouvez le modifier directement
4. Utilisez les outils de formatage :
   - Titres (H1, H2, H3, etc.)
   - Gras, italique, souligné
   - Couleurs de texte et de fond
   - Listes à puces ou numérotées
   - Alignement du texte
   - Liens et images

### 3. Sauvegarder ou annuler

- **Cliquez sur le bouton vert (icône disquette)** pour sauvegarder
- **Cliquez sur le bouton rouge (X)** pour annuler les modifications
- Un message de confirmation apparaît après la sauvegarde

## Sections éditables par page

### ProgramLanding (/)

Les sections suivantes sont éditables :
- Titre et sous-titre hero
- Description du programme ("¿QUÉ ES ALQUIMIA DEL CAMBIO?")
- Titre des modules
- Titre des bénéfices
- Titre "¿CÓMO FUNCIONA?"
- Titre des témoignages
- Biographie de la fondatrice
- Call-to-action final

### RetiroAmateLanding (/retiro-amate)

Les sections suivantes sont éditables :
- Titre et sous-titre hero
- Date et lieu du retiro
- Description de l'expérience
- Titre "¿POR QUÉ EL RETIRO ÁMATE ES PARA TI?"
- En-tête des prix
- Détails des prix
- Titre "¡3 DÍAS QUE LO CAMBIARÁN TODO!"
- Titre et description de la location
- Titre "¿POR QUÉ NUESTROS RETIROS SON DIFERENTES?"
- Biographie de la fondatrice
- Titre des témoignages
- Titre FAQ
- Call-to-action final

### PsychologyLanding (/psychology)

Les sections suivantes sont éditables :
- Contenu hero complet
- Introduction "Un enfoque humano y afectuoso"
- Titre des services
- Call-to-action final

## Persistance des données

- Les modifications sont **sauvegardées dans la base de données**
- Les contenus sont **conservés après actualisation de la page**
- Chaque landing page a son propre ensemble de contenus indépendants

## Notes importantes

⚠️ **IMPORTANT** : Ce système est temporaire et sera supprimé après que vous ayez fini les modifications. 

Pour l'instant, **n'importe qui peut modifier les textes** (pas d'authentification requise). Cela sera restreint aux administrateurs dans la version finale.

## Conseils d'utilisation

1. **Prévisualisation** : Vous pouvez voir le résultat en temps réel après avoir cliqué sur "Annuler" ou fermé l'éditeur
2. **Formatage** : Utilisez les outils de l'éditeur pour mettre en forme le texte (gras, couleurs, etc.)
3. **Sauvegarde** : N'oubliez pas de cliquer sur le bouton de sauvegarde (icône disquette verte)
4. **Annulation** : Si vous voulez annuler, cliquez sur le X rouge avant de sauvegarder

## Support technique

Si vous rencontrez des problèmes :
- Le bouton d'édition n'apparaît pas → Actualisez la page
- Le contenu ne se charge pas → Vérifiez que le backend est en ligne
- Erreur lors de la sauvegarde → Contactez le développeur
